# RuVoise — озвучка выделенной области экрана

**Зажмите боковую кнопку мыши 4 (XButton1), обведите область с текстом
от левого верхнего угла к правому нижнему и отпустите** — программа
распознает весь текст внутри области (офлайн OCR Windows) и произнесёт его
вслух. Пунктирная рамка тянется за курсором во время выделения, зелёная
рамка горит всё время, пока длится чтение.

Короткий клик (без движения) — читается **слово под курсором**.

Чтение снимает «снимок» экрана в момент отпускания кнопки: если после этого
картинка на экране изменится (диалог закроется, сцена сменится), чтение
всё равно продолжится и дочитает распознанный текст до конца.

## Возможности

- **Выделение области** — основной режим: OCR всей выделенной области,
  текст читается сверху вниз (все строки).
- **Клик — слово под курсором** (OCR, работает в играх и в любом приложении).
- Автоматических режимов «абзац/фраза/умный поиск» больше нет — читается
  только то, что вы явно выделили (или слово под курсором).
- **Настраиваемое назначение чтения (один слот)**: «Задать…» в настройках —
  нажмите кнопку мыши, **несколько кнопок сразу** (аккорд, например
  «Кнопка 4 + Кнопка 5») или клавиши — в том числе **аккорд из нескольких
  клавиш** (`6+7`, `Shift+G+H`, `Ctrl+R`, `F9`). Применяется сразу,
  перезапуск не нужен. «Убрать» снимает назначение («не задано»).
  Токены клавиш привязаны к виртуальным кодам — раскладка (RU/EN) не важна.
- **Выделение области с клавиатурным назначением**: нажмите сочетание
  (например `6+7`) — включится режим выделения; дальше клик левой кнопкой
  читает слово под курсором, обвод левой — область (с зелёной рамкой).
  Повторное сочетание или нажатие любой другой кнопки мыши выключает
  режим. С кнопочным назначением всё по-прежнему: зажать — обвести —
  отпустить.
- **Все настройки применяются сразу** — кнопки «Сохранить» нет.
- **Свернуть в трей**: крестик и кнопка «Свернуть в трей» прячут окно
  настроек, RuVoise продолжает работать из трея; выход — правый клик по
  иконке в трее → «Выход».
- **Синтез речи — всегда офлайн**:
  - **SAPI** (по умолчанию) — русский голос выбирается автоматически
    («Microsoft Irina Desktop - Russian»); при желании можно выбрать другой
    в списке голосов окна настроек — применяется сразу;
  - если SAPI недоступен, программа автоматически пробует
    **голоса Windows (WinRT)**;
  - **скорость и громкость** применяются сразу при отпускании слайдера
    (сохранять не нужно); скорость дублируется SAPI-тегом — работает и на
    «капризных» голосах.
  Синтез в память — начало чтения через ~0,3–0,5 с после отпускания кнопки.
- **Выбор устройства вывода** — см. раздел про Stream Deck ниже.
- **Подсветка**: зелёная рамка при выделении области и вокруг читаемого
  текста; горит всё время чтения и гаснет сама. Реализована как обычное
  окно с регионом-рамкой (как рамки захвата в сниппет-инструментах) —
  видна поверх окон, которые не отображают слоёные окна.
- **Без лишних окон**: RuVoise стартует свёрнутым в трей; окно настроек
  открывается через правый клик по иконке в трее → «Настройки».
- **Звуковая обратная связь**: один короткий тон — в выделенной области
  текст не распознан; нисходящий тон — синтез речи не удался.
- **Один экземпляр**: при запуске RuVoise закрывает окна старых копий и не
  даёт запуститься дважды (старая версия в трее — частая причина «странного»
  поведения).
- Автозапуск с Windows, иконка в трее (пауза/настройки/выход), кнопка
  «⚡ От администратора» в настройках.
- Повторное чтение того же текста — мгновенно (кэш синтеза).
- **Диагностика**: кнопка в окне настроек пишет состояние OCR/синтеза и
  текущий курсор в `logs/ruvoise.log`.

## Установка и запуск

1. Запустите `install.bat` (один раз; скачает зависимости в папку `.venv`).
2. Запустите `start.bat` — RuVoise стартует свёрнутым в трей
   (настройки — правый клик по иконке в трее).
3. Зажмите кнопку 4, обведите текст, отпустите.

Для диагностики можно запустить `run_console.bat` — будет видно лог.

**Если рамки не видно поверх игры** — игра работает в исключительном
полноэкранном режиме: Windows не позволяет рисовать поверх него что-либо.
Переключите игру в **«окно без рамки» (borderless)** в настройках
отображения игры — рамка появится. Чтение голосом работает в любом режиме.

Окна, запущенные **от администратора**, не видны непривилегированному
процессу — запустите RuVoise кнопкой **«⚡ От администратора»** в настройках.

## Stream Deck: вывод звука в наушники

В окне настроек, раздел **«Вывод звука»**:

- **«По умолчанию (следует за переключением звука в системе)»** — RuVoise
  каждый раз играет в то устройство, которое активно в системе. Если ваш
  плагин на Stream Deck переключает вывод «колонки → наушники», озвучка
  автоматически пойдёт в наушники. Это режим по умолчанию.
- Либо выберите **конкретное устройство** — тогда RuVoise всегда будет
  звучать там, независимо от переключений на Stream Deck.

## Настройки (data/config.json)

| Ключ | Значение |
|---|---|
| `trigger` | триггер чтения/выделения: `x1` (по умолчанию), `x2`, `middle`, с модификаторами — `ctrl+x1`, `ctrl+shift+x2` |
| `key_hotkey` | клавиатурное сочетание чтения слова (пусто = не задано), например `f9`, `ctrl+shift+r` |
| `engine` | `sapi` (по умолчанию) или `winrt` — оба офлайн |
| `sapi_voice` | имя системного голоса (пусто = авто-выбор русского) |
| `winrt_voice` | id голоса Windows |
| `rate`, `volume` | скорость (−50…+100 %, по умолчанию 30) и громкость (0–100 %) |
| `device_name` | `default` или имя устройства вывода |
| `overlay` | зелёная рамка вкл/выкл |
| `max_read_chars` | предел длины озвучиваемого текста (по умолчанию 1500) |
| `ocr_grab_w/h`, `ocr_scale` | область захвата вокруг курсора и увеличение |
| `ocr_lang` | `auto` или тег языка (`ru-RU`) |

## Ограничения и подсказки

- **Игры**: захват и рамка работают в оконном режиме и «окно без рамки»
  (borderless). В исключительном полноэкранном режиме игра может блокировать
  захват (OCR увидит чёрный экран) — переключите игру в borderless.
- Окна, запущенные **от администратора**, не видны непривилегированному
  процессу (захват и рамки) — запустите и RuVoise от администратора.
- Текст внутри картинок OCR читает; качество зависит от размера шрифта
  (область автоматически увеличивается перед распознаванием).
- Если ничего не находится: нажмите **«🔧 Диагностика»** в настройках и
  посмотрите/пришлите `logs/ruvoise.log` из папки программы.
- Для офлайн-голоса SAPI: если системных русских голосов нет, установите
  языковой пакет: *Параметры → Время и язык → Язык и регион → русский →
  Параметры языка → Речь*.
- Windows OCR требует языковых компонентов: на этой системе доступны
  `ru` и `en-US` (проверяется кнопкой диагностики).

## Состав проекта

```
RuVoise/
├── run.py              — точка входа (запускает пакет из src)
├── start.bat           — запуск без консоли
├── run_console.bat     — запуск с консолью (для диагностики)
├── install.bat         — установка зависимостей в .venv
├── requirements.txt    — зависимости
├── src/ruvoise/        — код программы
│   ├── main.py         — сборка приложения (OCR — в GUI-потоке,
│   │                     синтез и звук — в рабочем потоке)
│   ├── ocr_reader.py   — захват области экрана (GDI) + Windows OCR
│   │                     (read_at — вокруг курсора, read_area — область)
│   ├── tts_engines.py  — офлайн-синтез речи: SAPI и голоса Windows (WinRT)
│   ├── audio_out.py    — воспроизведение и выбор устройства вывода
│   ├── overlay.py      — зелёная рамка-подсветка (обычное окно
│   │                     с регионом-рамкой)
│   ├── mouse_hook.py   — глобальный перехват кнопок мыши и клавиш
│   │                     (триггер чтения/выделения)
│   ├── settings_gui.py — окно настроек
│   ├── tray.py         — иконка в системном трее
│   ├── app_config.py   — настройки (data/config.json) и папки data/logs
│   ├── win_util.py     — DPI-awareness, автозапуск, одна копия
│   └── logutil.py      — журнал (logs/ruvoise.log)
├── data/               — config.json и кэш синтеза (data/cache)
└── logs/               — logs/ruvoise.log
```
